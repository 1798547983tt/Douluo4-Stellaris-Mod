# 页面与组件清单

正常路径从 src/atlas.mjs 的 mountAtlas → render 开始。固定资产栏和可折叠导航在各页面间共用。下表中的文件均在 src/ 下。

| 页面 | 入口与依赖 | 主要数据与操作 |
| --- | --- | --- |
| 星图 | atlas.renderMap → flightdeck.sectorInstruments、console-view.territoryShape | 已知恒星系、领地、航道、己方在场舰船、生态标记与星域分布；筛选、搜索、平移和缩放 |
| 恒星系／行星 | atlas.renderSystem、renderPlanet → console-view.orbitalChart、survey-globe、ui-model.estimateRoute | 星球、卫星、设施、舰船、生物与天然宝地；约计人口、产业、特产；公共或自有交通 |
| 外交与贸易 | desk-panels.commandPanel(diplomacy) → flightdeck.relationScope | 已接触组织、好感、地位与准入；通讯、询价、服务、购买 |
| 舰船设计器 | atlas.renderDesigner → ui-model.availableCatalog、assembleDesign、shipDrawing | 五类基础船体、兼容槽、配件与模型、属性和委托报价 |
| 舰队编辑器 | desk-panels.commandPanel(fleets) | 已有舰只、编组、部署与燃料／护盾／船体整备；航母机库 |
| 玩家装备 | atlas.renderEquipment → ui-model.dualArmorStatus | 十一斗铠部位和自定义图、套装、整体机甲等级与双甲状态 |
| 星海图鉴 | atlas.renderCodex | 已遇物种的四档强度、折叠档案、组织和行星；生成参考与玩家发现分开展示 |
| 科技 | desk-panels.commandPanel(tech) → flightdeck.technologyCircuit、command.STUDIES | 研究节点与前置连线、选中详情、研究请求、自拟课题 |
| 养成 | desk-panels.commandPanel(growth) → atlas.openGray、renderGray | 星门调查、开启、探索、重逢门槛、灰风形态／好感／婚纱；四位伙伴的事件进度 |
| 玩家内政 | desk-panels.commandPanel(governance) | 组织、授权与控制来源、库存、船坞订单、外交地位 |

## 跨页面组件

atlas.mjs 内部的 el、sv、btn、icon、facts、chip、pageHead 用于构建元素；commandPanel 接收这些工厂以及当前数据和动作回调。src/flightdeck.mjs 接收界面上下文，构建可交互仪表。viewBox、星图位置、缩放状态与投影共同决定命中区域。调整圆点或文字尺寸后，检查鼠标、触屏与键盘操作。

所有立绘、舰型、机甲与字体入口见 assets/ 和 scripts/build*.mjs。字体通过宿主系统字体回退。源码中没有独立的 React 组件库、TypeScript 应用或需要另外安装的字体包。
