# 前端美化指南

打开预览，先看航图和右侧星域分布环，再进入船坞和科技树。三者分别管理空间位置、装配关系和技术依赖。保留各自的读图顺序，同时共用舰桥的浅色舱框与导航语法。

## 材质与颜色

四层 CSS 的真实加载顺序为 atlas.css → command.css → flightdeck.css → pearl.css。atlas.css 提供基础组件，command.css 承载扩展栏与布局，flightdeck.css 定义切角、仪表与各功能页构图，pearl.css 是本次 V8 的最终浅色主题。生成的 atlas-style.generated.mjs 由构建器写入。

- 大面积使用珍珠白、冰蓝、浅天蓝；正文在玻璃上使用深色墨线。局部模型图、阴影和描边可保留深色。避免将整页底板还原为藏蓝。
- 冰蓝／青用于导航和定位。翡翠绿用于外交与生态，琥珀橙用于船坞，紫罗兰用于科研，香槟金用于装备和授权；玫瑰紫用于伙伴。危险使用警示红，正文中保留状态词和徽标。
- 阵营色来自 ui-model.factionOf。阵营归属、对玩家态度、当前选中是三种含义。不要用同一个红点同时承担三者。
- 主景先于表格。舰体保留在插槽之间，科研连线指向真实前置，整备条使用当前值和真实上限。缺少记录时显示未调查状态，避免用虚构趋势填满面板。

## 适合下一轮的具体工作

| 区域 | 可调整内容 | 检查方法 |
| --- | --- | --- |
| 航图 | 小字对比度、密集星域的标签避让、边界与刻度密度 | 联邦、龙马、中立、敌对均可辨识；新增星系和缩放后命中位置正确 |
| 船坞和装备 | 深底模型图与白玻璃的衔接、舰影裁切、窄屏槽位和触摸区 | 逐一切换五种船体与六档机甲，保持轮廓完整；上传自定义图后可恢复 |
| 外交和编队 | 网络与权限状态、多个基地的分组、空编队 | 同势力与跨势力切换时，关系、库存及整备数值对应同一对象 |
| 科研 | 键盘选择、超宽树滚动、解锁与不可用状态 | 选择节点同步详情，前置不足不能下达研究 |
| 灰风和图鉴 | 婚纱解锁提示、星门七格、资料可读性、窄屏折叠 | 分别测试事件前、开门后、重逢后、满好感；减少动效时依然可识别状态 |

## 兼容约束

样式位于 Shadow DOM；修改外层酒馆 CSS 不能替代组件样式。保留控件名称、键盘焦点、SVG 的点击热区和减少动效选项。让长中文名称、未知人口、零余额、大舰队与空档案参与验收。对预览的美术确认不能替代真实酒馆对脚本、变量和楼层重放的测试。

外观提交请避免同时改动 stat_data.星际、事务格式、知识投影、门槛与支付计算、旧档迁移，或原卡脚本标识和工坊哈希。若确实需要变更其一，应单独说明玩法影响并补相应回归。
