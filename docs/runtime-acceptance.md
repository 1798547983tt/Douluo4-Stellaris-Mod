# 真实酒馆验收矩阵

安装目标：角色卡测试副本；不要覆盖唯一聊天。当前各项均未在真实酒馆执行。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 初始化 | 新开斗四聊天并进入空间站 | 原卡人物正常；星际世界产生相关记录 |
| AI细化 | 询问站内具体部门和工作人员 | AI补全原对象，不重复建同名空间站 |
| 硬规则 | 剧情要求太空生命掉魂环 | 规则拒绝；不保存非法物种 |
| 原子失败 | 在测试消息中提交一条合法一条非法操作 | 两条均不保存，下一轮出现错误纠正提示 |
| 普通回复 | 连续旅行、交易、战斗 | 资源只扣一次，战报与后续剧情一致 |
| Swipe | 同一楼生成不同路线并切换 | 世界状态随选中页改变，原页仍可恢复 |
| 编辑/删除 | 修改或删除改变资源的一楼 | 后续状态从当前真实分支重建 |
| 切聊天 | 在两个测试聊天之间往返 | 档案、注入和资源不串档 |
| 刷新 | 重新载入酒馆并回到聊天 | 从保存消息重放，原卡人物与其他组件字段保留 |
| MVU共存 | 原卡普通升级/换幕 | 星际字段未被Root过滤；原状态栏和剧情窗口正常 |
| 特殊存在 | 进入登记的利维坦栖地 | 不随机换等级或位置；可观察/撤退，不强迫战斗 |
| 长聊 | 100+轮并新增大量档案 | 记录容量、消息文件体积、模型上下文与重放耗时 |

后端快照的重放来源是当前选中的助手消息事务。请保留原始DL4Space块；只使用显示正则隐藏它，不删除原始块。任何聊天清理器若删掉事务，历史恢复将相应失去来源。
