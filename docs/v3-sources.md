# v3设定来源与改编边界

查阅日期：2026-11-18。本文记录概念来源，不把预览数值认定为原著事实，不收录游戏原始图像、模型或完整事件台词。

## 斗罗

- [斗四第432章：赖上我了？](https://www.69shuba.com/txt/29586/21058392)：机甲分级与双甲流语境。机甲是整体载具；双甲流将穿戴斗铠的魂师与适配机甲配合。
- [斗四第304章：永恒天空城](https://lnmtl.com/chapter/douluo-dalu-4-final-douluo-chapter-304)：斗铠字数分级及未来层次的讨论。不同剧情阶段对理论上限与实际成品的语境不同，本MOD不为每字给出一个武断、统一的魂力门槛。
- [斗四第1611章：取名六字斗铠](https://lnmtl.com/chapter/douluo-dalu-4-final-douluo-chapter-1611)：六字斗铠及命名语境。链接为公开翻译镜像，原作优先。
- [Soul Land Wiki：Battle Armor](https://soulland.fandom.com/wiki/Battle_Armor)：检索条目对应十一部位与一至六字分级。直接抓取失败，所用线索来自检索摘要与章节交叉核对。
- [斗四设定汇总](https://bkso.baidu.com/item/斗罗大陆IV终极斗罗/23205006)：作为分级辅助索引，白/黄/紫/黑/红/金机甲、斗铠翼/领域/灵性及高阶孕养。不是独立于原作的优先来源。

实施：十一斗铠部位，一至六字及对应名字长度；整体机甲六级，天翼类变形属于具体机甲features，不默认所有机甲都有。双甲协同的具体数字来自角色实际装备记录，展示用数值是合成样例。五、六字进化依剧情条件，不用菜单直接制造或凭固定等级赠送。

## 群星

- [群星中文维基：舰船](https://qunxing.huijiwiki.com/wiki/舰船)：武器尺寸、专用槽、辅助与核心系统概念。MOD采用S/M/L/X/G/P/H与独立U/A/R/E/J/C功能槽；U是本MOD简化防护槽，并非逐项复刻游戏全部舰段配置。
- [太空兽群](https://qunxing.huijiwiki.com/wiki/太空兽群)、[太空实体](https://qunxing.huijiwiki.com/wiki/太空实体)：物种概念及独立实体分类。
- [岩居兽](https://qunxing.huijiwiki.com/wiki/岩居兽)：Cutholoid伪装小行星、吞噬生物与舰船；不把它误当作虚空虫Voidworm。
- [缇扬奇](https://qunxing.huijiwiki.com/wiki/缇扬奇)：温顺迁徙与巨行星气体摄食的生态概念。
- [星神兽](https://qunxing.huijiwiki.com/wiki/星神兽)、[Guardians镜像](https://stellaris.fandom.com/wiki/Guardians)：以太巨龙、缇扬奇族母、噬星者、位面之魇等独特空间实体概念。
- [Lost Amoeba镜像](https://stellaris.fandom.com/wiki/Lost_Amoeba)：泡泡是可结识的迷失变形虫幼体个体，不是另一个巨大物种。
- [L星团](https://qunxing.huijiwiki.com/wiki/L-星团)、[L-Cluster镜像](https://stellaris.fandom.com/wiki/L-Cluster)：Gray纳米实体的形态转换及被摧毁后的长期重构概念。

官方英文Wiki直连返回401，因此没有声称完成官方页面全文阅读。中文维基及镜像的检索结果用于上述概念核对；无版本依赖的原版战力数值被移植。

实施：模板包含12项，实例只在实际探索时登记；每个实例等级按用户指定四档转换。该等级映射、舰体参数、自然攻击、槽位数量、初始船体和配件数值均为MOD设计，不是群星的魂力等级设定。模板库不是已发现图鉴，也不会每种强制刷出。

## 灰风二创

原版来源只用于纳米人格、变形与重构概念。成熟女性人格、穿越无数平行世界、只爱玩家、唯一伴侣的爱情背景完全依据本次用户要求。没有冒称移植某一个具体恋爱MOD的代码、台词或立绘。

前端头像与舰船图均为自写SVG概念图。灰风的舰体、护盾、主炮、转换消耗与纳米物质规则是MOD数值；重构沿用十年叙事概念。不以她爱玩家为由替玩家决定恋爱回应。
