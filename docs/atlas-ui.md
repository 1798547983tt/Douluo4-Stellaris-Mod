# 星海导航前端 v3

新版前端内嵌现有「斗四星际后端」脚本，随同一个工坊作品version 3安装。无需另导入前端，无新增CDN或API服务。

## 打开与升级

导入新版「斗四星际MOD-一键安装.script.json」至酒馆助手角色脚本库，开启并确认安装/升级，再重新进入聊天。点击左下角蓝白四角星打开悬浮窗。桌面可拖动顶栏与右下角缩放；窄屏自动调整。旧版用户先停用旧安装器，新安装器会交给原工坊内核撤下v1并安装v3；装好后安装器可停用，后端独立运行。

初次没有星系时点「完善星图」，确认行动后AI按当前正文建立档案。真实存档不会加载预览场景。资料不会在点击后凭空出现，须等待正常模型回复并通过事务校验。

## 四个栏目

- **星域导航**：势力/敌对筛选、搜索、缩放和平移；联邦、龙马、独立中立组织、游牧与海盗有不同徽标。星系→行星→天然宝地逐级浏览，显示行星类型、宜居度、成长上限、殖民状态及已知生态信号；设施显示所属、服务和准入。区域色块根据已知控制星系绘制，是导航示意，不是真实天文距离和领土边界。
- **舰船设计**：五种7/10/14/15/17个独立专用插槽的初始船体、15种初始配件，按槽位、电力、质量、尺寸联合校验；预览为随配置变化的矢量蓝图。显示防护、动力、航速、通信、舰员、舱室、武器、成本和建造时间。图纸提交不会自动获得战舰，建造仍需船坞、材料与时间。
- **机甲/斗铠**：斗铠按一至六字及十一部位，机甲为白/黄/紫/黑/红/金级完整载具；只可选择已持有部件，穿戴前由正文核对条件。显示斗铠名、套装进度、部件合计、未激活/已激活整套加成，不改写原卡人物属性。
- **太空图鉴**：常见70—99、危险群落个体100—110、区域霸主111—120、利维坦121—150，四类可折叠；按正文遭遇、扫描或可靠资料逐步解锁。未知弱点和隐藏利维坦不提前公开。行星旁生物标记表示邻近活动，不代表不可宜居天体诞生原生生命。

## 交通与行动

默认公共星系交通，每段航路minutes+360分钟换乘、星系内180分钟。私人战舰只列实际持有的舰船，跨系按每段ceil(minutes/speed)估算，并检查当前位置、就绪状态、燃料及逐段补给；星系内接驳按60/speed估算。未知航路不提供假天数。封锁、许可、地表长途等附加时间须由正文明确结算。

「前往」「穿戴」「提交图纸」「调查」先展示将发送的文本，再创建一条正常user消息并触发正常回复。确认绑定世界修订与分支标识，换聊天/等修订swipe使旧确认失效，生成中拒绝重复提交，不覆盖输入框草稿。消息写入后触发失败会提示手动继续，并禁止原确认框重发。

公共行程由publicTravel结算，已推进时间，不要再次advance同一旅程。目的星球/宝地通过正文places及focusIds记录；后端硬位置目前为恒星系及places。

## 数据和依赖

唯一世界状态仍为消息楼层stat_data.星际，由当前swipe分支重放恢复。21类档案，新增equipment、ownership、equip、publicTravel及可选坐标、行星类型、生物邻近行星、组织对玩家态度。界面只获取已知字段和自有舰船/装备公开档案，secrets不进入DOM；文字用textContent构造。

组件运行于酒馆助手角色脚本iframe，尝试挂载至可访问的parent.document，不能访问则使用本iframe。界面状态及设计草案仅存组件内存，关闭/重载不持久化草案。代码为src/atlas.mjs、atlas.css、ui-model.mjs，经scripts/build.mjs合并至原脚本；原卡ZOD增加星际及星际待办两个可选字段。

本机已核ST1.19.0、酒馆助手4.11.3；原卡远程MVU保持原加载方式。行动API依据本机chat_message.d.ts的createChatMessages([{role:'user',message:text}])及triggerSlash('/trigger')声明/源码；实际宿主调用时序待验。

## 预览与验证

「星海导航-预览.html」可双击打开，使用同一维护源码与合成场景，不连接酒馆、不写真实存档。构建命令：node scripts/preview.mjs --build-only。source SHA256记录于前端预览证据.json。

自动化检查覆盖航行结算、装配、装备、知识隔离、提交锁与分支、原工坊v1→v3升级及卸载。浏览器预览检查四栏目、行星导航、交通切换、装配约束、套装展示、图鉴折叠与320px窄屏。它们不替代真实ST验收，driverAccepted=false。

真实宿主待验：左下角入口、父文档层级、正常user/assistant生成、事务后刷新、MVU晚写、swipe/编辑/删楼/换聊天、旧版升级只有一份后端、原卡剧情窗口/状态栏共存、手机设备键盘与触控、远程MVU加载。没有修改用户ST程序、角色卡或聊天。
